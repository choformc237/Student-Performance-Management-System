# Student Performance Management System

**For: Chi McDonald**

A Python-based Student Performance Management System for tracking, analyzing, and predicting student academic performance.

## Features
- Add and manage student records
- Track grades and performance metrics
- Basic performance prediction using simple models
- Data preprocessing and analysis tools

## Setup
1. Clone the repository
2. Install dependencies: `pip install -r requirements.txt`
3. Run: `python main.py`
